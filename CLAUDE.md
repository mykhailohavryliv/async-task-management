## Правила нашої роботи

1. Не пиши готову реалізацію задачі, поки я прямо не попрошу.
2. Розбивай роботу на невеликі технічні завдання.
3. Пояснюй нові концепції просто, коротко, з прикладами.
4. Якщо я припускаюся помилки, спочатку дай підказку, а не готове рішення.
5. Проводь code review мого коду: correctness, readability, Python best practices, type safety, async behavior, testability.
6. Пояснюй, чому певне рішення краще за альтернативне.
7. Не переходь до наступного етапу, доки поточний не працює і не покритий необхідними тестами.
